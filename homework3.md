**Список ингредиентов и цены**

- [ ] Доступны все 6 ингредиентов, отсутствуют лишние.
- [ ] Цены за одну порцию соответствуют требованию:

| Ингредиент | Цена, руб. |
|---|---:|
| Пепперони | 60 |
| Ветчина | 70 |
| Грибы | 50 |
| Лук | 30 |
| Оливки | 40 |
| Бекон | 80 |

**Добавление ингредиентов**

- [ ] Каждый из 6 ингредиентов можно добавить, если он ещё не выбран и общий лимит не достигнут.
- [ ] При добавлении ингредиента добавляется ровно одна порция.
- [ ] После добавления ингредиента кнопка его добавления блокируется.
- [ ] Повторное добавление выбранного ингредиента невозможно, в том числе при быстрых повторных нажатиях.
- [ ] При выборе от 1 до 4 ингредиентов кнопки добавления невыбранных ингредиентов доступны.
- [ ] При 4 выбранных ингредиентах можно добавить пятый.
- [ ] После добавления пятого ингредиента блокируются все кнопки добавления.
- [ ] Добавить шестой ингредиент невозможно, в том числе при быстрых нажатиях на разные кнопки.

**Удаление ингредиентов**

- [ ] Каждый выбранный ингредиент можно удалить.
- [ ] При удалении исчезает только выбранный ингредиент; остальные сохраняются.
- [ ] Удалённый ингредиент можно добавить повторно.
- [ ] После удаления одного из 5 ингредиентов кнопки добавления невыбранных ингредиентов становятся доступны.
- [ ] При этом кнопки добавления оставшихся выбранных ингредиентов остаются заблокированными.
- [ ] Нельзя удалить ингредиент, которого нет в составе.

**Состояние без ингредиентов**

- [ ] При отсутствии ингредиентов отображается уведомление с точным текстом: «Необходимо добавить хотя бы один ингредиент».
- [ ] При отсутствии ингредиентов кнопка удаления заблокирована.
- [ ] Нажатия на заблокированную кнопку удаления не изменяют состояние.
- [ ] При отсутствии ингредиентов доступны кнопки добавления всех 6 ингредиентов.
- [ ] Из пустого состояния можно добавить один ингредиент.
- [ ] После добавления первого ингредиента его можно удалить, а повторное добавление этого же ингредиента заблокировано.

**Граничные значения и последовательности действий**

- [ ] Проверены состояния с 0, 1, 4 и 5 ингредиентами.
- [ ] Проверены переходы: 0 → 1, 1 → 0, 4 → 5 и 5 → 4.
- [ ] При переходе 1 → 0 появляется указанное уведомление и блокируется удаление.
- [ ] После нескольких циклов добавления и удаления ограничения продолжают действовать.
- [ ] Лимит в 5 ингредиентов работает для каждой из 6 возможных комбинаций состава.
